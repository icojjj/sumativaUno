# sumativaUno

Evaluación Sumativa 1 — Desarrollo Frontend

## Descripción

Proyecto de portafolio personal desarrollado como evaluación sumativa para el curso de Frontend. Implementa una página web responsive con las siguientes secciones:

- **Inicio (Hero):** presentación con llamados a la acción.
- **Sobre mí:** breve descripción personal.
- **Habilidades:** tarjetas con barras de progreso animadas.
- **Proyectos:** cards de proyectos destacados.
- **Contacto:** formulario con validación en JavaScript.

## Tecnologías usadas

| Tecnología | Descripción |
|---|---|
| HTML5 | Estructura semántica de la página |
| CSS3 | Estilos, variables CSS, Flexbox, Grid y diseño responsive |
| JavaScript (ES6+) | Menú móvil, animaciones con `IntersectionObserver` y validación de formulario |

## Estructura de archivos

```
sumativaUno/
├── index.html   # Página principal
├── styles.css   # Estilos globales
├── script.js    # Lógica interactiva
└── README.md    # Este archivo
```

## Cómo ejecutar

Abre `index.html` directamente en cualquier navegador moderno — no requiere instalación ni servidor.
